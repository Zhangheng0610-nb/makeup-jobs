📱 一键更新

云端自动跑「扩大搜索」更新，找到更多宁波化妆师好岗位，大约 10-30 分钟完成。

📊 现在是什么状态？点一下就知道

显示：网站现在几条岗位、最近一次更新几点 / 成功 / 失败。不用登录也能看。

1 推荐：直接打开 GitHub 点按钮

打开 GitHub 更新页面
  1. 如果页面让你登录 → 先点右上角 Sign in 登录（用你的 GitHub 账号）
  2. 登录后，页面右上角有个紫色按钮 「Run workflow」
  3. 点「Run workflow」→ 分支保持 main → 点绿色 「Run workflow」 → 完成！
  4. 等 10-30 分钟后回来刷新网站，就能看到新岗位
❓ 没有看到「Run workflow」按钮？说明没登录成功，先登录，按钮就出现在右上角。

2 更省事：设置一次令牌，之后点一下就行

按下面步骤设置一次（约 2 分钟），以后更新只点一个按钮，不用再找「Run workflow」。

① 打开 GitHub 创建令牌
  1. 名字随便填（已自动填好），有效期选 No expiration（永不过期）
  2. 直接拉到最底部，点绿色 Generate token
  3. 复制生成的 ghp_xxxx 开头的长串
  4. 粘贴到下面，点「保存令牌」

3 开始更新

⚠️ 30 分钟内重复点击只生效一次（防误触浪费）。设置过的令牌只存在你自己的手机浏览器里，不上传任何地方。

常见问题

GitHub 页面打不开？ 换用电脑上桌面「一键更新化妆师岗位.bat」也能更新。
点了 Run workflow 没反应？ 等几秒刷新页面，出现黄色「queued」圆点就是成功了。
令牌过期了怎么办？ 重新走第 2 步创建一个，替换旧的。
